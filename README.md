# TaskFlow – Gestor de tareas

Aplicación web desarrollada como proyecto de la asignatura Aplicaciones Web. Permite gestionar tareas mediante una SPA (Single Page Application) desarrollada con Vue 3, una API REST con Node.js y Express, e implementación de características PWA (Progressive Web App).

## Tecnologías utilizadas

- **Frontend:** Vue 3, Vue Router y Vite.
- **Backend:** Node.js y Express.
- **API:** REST con operaciones CRUD.
- **Persistencia:** Archivo JSON.
- **PWA:** Manifest y Service Worker.
- **Despliegue:** Render.
- **Control de versiones:** Git y GitHub.

## Funcionalidades

- Crear nuevas tareas.
- Consultar tareas registradas.
- Editar tareas existentes.
- Eliminar tareas.
- Cambiar el estado de las tareas.
- Navegación entre vistas mediante Vue Router.
- Instalación como aplicación PWA.
- Acceso a la interfaz principal sin conexión, con limitaciones en las operaciones que requieren la API.
